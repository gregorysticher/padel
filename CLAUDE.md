# Consignes Claude Code

## TODO.md (à tenir à jour à chaque fin de séance)

- `TODO.md` à la racine, ligne « Dernière mise à jour : AAAA-MM-JJ » en tête.
- Section « ## À faire par Greg » : cases à cocher `- [ ]`, uniquement ce que Greg
  seul peut faire ou décider, avec l'échéance quand elle est connue
  (`— échéance : AAAA-MM-JJ`) et de quoi agir sans relire la séance.
- Si plusieurs sessions travaillent dans ce dépôt : une sous-section `### Sujet`
  par sujet, chaque session n'édite que la sienne, jamais tout le fichier.
- Le backlog de Claude vient ensuite, dans une autre section.
- À chaque fin de séance : mettre à jour, commit et push. Le briefing quotidien
  de Greg lit la copie GitHub.
- Créer `TODO.md` dès qu'une action revient à Greg.
- Ce dépôt est public : n'y écrire aucune donnée personnelle.

## Agenda et rappels

- Ne jamais créer, déplacer ni supprimer d'événement dans les agendas Google de
  l'utilisateur sans le lui demander d'abord.
- Pour un rappel ou une action datée : créer une tâche programmée Claude dans la
  session concernée (`send_later`), et noter l'échéance dans `TODO.md`
  (`— échéance : AAAA-MM-JJ`) pour que le briefing quotidien la reprenne.
